This is an (as yet) unlisted extension for Thunderbird that automatically deletes the attachments
from the local copy of a sent message. Long time ago, there used to be an extension that allowed
the user to enable this as an option, and I liked it very much, as it made Thunderbird's profile
folder much lighter and faster, and saved a lot of space. After all, one attaches a file already
on one's disk, so why save another copy in a mail folder? I finally got to designing a web
extension with this function (with the help of AI), and the result is this add-on.

Be aware that the specific type of action performed - deleting attachments - CANNOT BE UNDONE.
The present, rudimentary, version of the extension works for all messages sent from (a single copy of)
the Thunderbird app, so for all accounts, all recipients, etc. It does not work on a specific
folder, so it is compatible with Günter Gersdorf's extension that allows the user to select the folder
where the local copy of a message is stored (Copy Sent To Current PWE, https://addons.thunderbird.net/nl/thunderbird/addon/copy-sent-to-current-pwe/).
